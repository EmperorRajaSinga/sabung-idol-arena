SABUNG IDOL ARENA - CLOUDFLARE WORKERS DEPLOYMENT

PROJECT CONFIGURATION
- GitHub repository: https://github.com/EmperorRajaSinga/sabung-idol-arena
- Deployment branch: zip-update
- Build command: npm ci && npm run build
- Build output directory: dist
- Worker configuration: wrangler.jsonc

AUTOMATED DEPLOYMENT SETUP
1. Open the GitHub repository settings.
2. Open Secrets and variables, then Actions.
3. Add these repository secrets:
   - CLOUDFLARE_API_TOKEN
   - CLOUDFLARE_ACCOUNT_ID
4. Create a Cloudflare API token with permission to edit and deploy Workers.
5. Copy the Cloudflare account ID from the Cloudflare dashboard.
6. Push a commit to the zip-update branch.
7. Open the Actions tab and verify the "Deploy to Cloudflare Workers" workflow completes.

The workflow runs the TypeScript checks, tests, production build, and Cloudflare Workers deployment.

MANUAL DEPLOYMENT
From the project directory, run:
   npm ci
   npm run lint
   npm test
   npm run build
   npx wrangler deploy

The worker serves the static assets from dist/ and uses single-page application routing.

SECURITY
Never commit API tokens or private credentials. Store deployment credentials only as encrypted repository secrets.
